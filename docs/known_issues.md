# Известные дефекты и что делать при сбоях

## Дефекты исходных данных, которые генератор исправляет

Каждый из них проходил проверку «на форму массивов» и молча портил бы результат.

| Дефект | Без исправления | После |
|---|---|---|
| каждая комната нормирована своим множителем | высоты потолков в одном доме различались в 1.31 раза | точные метры по мебели, см. [metric_scale.md](metric_scale.md) |
| шов панорамы | 14.65 % двумерных рамок во весь кадр | 0.30 % |
| камера над мебелью | 34.3 % кадров | около 1 %, и это камеры под светильниками |
| чужая плита пола в контуре | контур в 2.48 раза больше комнаты | медиана 1.04 |
| грубые классы переработки | один класс содержал 43.9 % предметов | крупнейший — 26 % |
| нет архитектуры у трети комнат | комнаты без стен, стены без материалов | стены, полы и потолки из исходного релиза |

Мнимый дефект: около 4.6 % предметов эталона нет в масках экземпляров. Это не потеря:
рендерер не пишет запись для предмета, полностью закрытого другими. В COCO такого
предмета нет, в трёхмерной разметке он есть; оба варианта правильные.

## Ошибка разметки, которая была найдена и исправлена

Контур с лишними вершинами давал ложные углы и ложные стены в отношениях. Теперь контур
очищается (`dataset/contour_cleanup.py`), это проверяют тесты.

## Свойства источника, которые остаются

- Многоуровневые и декоративные потолки описываются одной высотой.
- У 177 комнат в плане есть дыры. Эталон хранит их вместе с внешним контуром: адаптер,
  которому нужен только внешний контур, должен отбросить дыры сам.
- У рамок нет «переда»: поворот на 180° неотличим, см. [output_format.md](output_format.md).
- Дверные проёмы серые, глубина за проёмами неполна.
- У 5.8 % комнат потолок чёрный: лампы не достают до ниши.
- Разбиение по домам не исключает геометрических дубликатов под разными идентификаторами.

## Что делать при сбоях

| Сообщение или признак | Причина | Что делать |
|---|---|---|
| `export`/`validate`: `rooms of this experiment differ from its split` | `splits/rooms.jsonl` эксперимента не совпадает с его же `train/val/test.txt`, например после ручной правки | менять состав только через `reject`; при новом разбиении — новый эксперимент |
| `render`: `Completed room was made with different code/settings` | изменился код рендерера или `--samples`, `--views`, `--min-clearance` | новая выходная папка |
| правка архитектуры или GLB не подхватилась | хеши проверяют только код, не исходники | новая выходная папка |
| `FileExistsError: Use an empty output directory` | рендерер не пишет в непустую папку | `render` очищает её сам; после `render-room` очистить вручную |
| стены и пол чёрные | загружены и конструкции переработки, и архитектура: две поверхности в одной плоскости | рендер с `--architecture`, тогда конструкции переработки пропускаются |
| `FAILED ...: no architecture` | нет `<архитектура>/<дом>/<комната>/architecture.obj` | выполнить `architecture` для этих комнат |
| `No matching ceiling patch` | у потолка нет подходящего горизонтального участка | исключить комнату через `reject` с причиной |
| `Only N distinct poses satisfy clearance` | тесная комната или много мебели | `reject`; `--allow-relaxed-clearance` — только осознанно |
| `export` останавливается на `Scale checks failed` | масштаб комнаты неправдоподобен | `reject --rooms ... --reason ...` или временно `--allow-unscalable` |
| в эталоне пропали `relations` или `attributes.shape` | отдельно перезапущен этап `ground_truth` | заново `relations`, `shape` и всё, что от них зависит |
| в COCO предмет разрезан на две рамки | предмет охватывает шов в обоих кадрах | так задумано, см. [output_format.md](output_format.md) |
| сломались перечни видов после переноса эксперимента | в `manifests*/` и эталоне абсолютные пути к PNG, HDF5 и сеткам | не переносить эксперимент или переписать пути |
| числа на разных наборах не сравниваются | набор другого размера даёт другой список классов | сравнивать только в пределах одного `classes.json` и одного разбиения |
| мебель сдвинута относительно стен | `architecture` не совместила системы (мало общей мебели) или масштаб неверен | посмотреть `architecture.json` (`matched`, `floor_from`) и сами панорамы |

## Правила, которые держат набор честным

1. **Ничего не исключается молча.** У каждой исключённой комнаты есть причина и
   обоснование, а число комнат сверяется при каждом чтении разбиения.
2. **Исходники не меняются.** GLB не удаляются и не правятся, геометрия не достраивается.
3. **Разбиение по домам.** Тестовая часть не используется для выбора весов.
4. **Один контур на всю разметку.** Отношения и все форматы, построенные по эталону,
   используют один и тот же очищенный контур.
