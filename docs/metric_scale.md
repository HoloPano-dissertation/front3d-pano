# Восстановление метрического масштаба

Переработка MIDI-3D нормирует **каждую комнату своим множителем**: оболочка любой комнаты
занимает около 1.9 единицы, каким бы ни был её настоящий размер. Если считать единицы
метрами, высоты потолков в одном доме различаются в 1.3 раза, а рамки предметов нельзя
сравнивать между комнатами. Поэтому на каждую комнату восстанавливается один множитель
«метров на единицу».

Код: `src/front3d_pano/dataset/source_metadata.py` (команда `metadata`) и
`src/front3d_pano/dataset/metric_scale.py`.

## Точный масштаб по мебели

1. Для каждого предмета комнаты по идентификатору из имени GLB находится его модель
   в описании сцены исходного 3D-FRONT.
2. Настоящий размер = размер модели × масштаб экземпляра в комнате.
3. Сравниваются **отсортированные** размеры: рамка в нормированных единицах против
   настоящей в метрах, по отношению на ось. Сортировка снимает вопрос, какая ось какая.
4. Масштаб комнаты — медиана всех отношений, разброс — среднее отклонение от неё,
   делённое на масштаб.
5. Комната не получает масштаба, если сопоставлено меньше двух предметов или разброс
   больше 0.15: мебель не сходится на одном масштабе.

Результат — таблица `scales` в `source_metadata.json`, источник масштаба в разметке — `table`.

## Запасной масштаб по высоте потолка

Если точного масштаба нет, принимается, что потолок на высоте 2.6 м:
`масштаб = 2.6 / (потолок − пол)`, источник — `ceiling_height`. Точность ограничена тем,
насколько потолок конкретной комнаты отличается от 2.6 м. Высота меняется ключом
`--reference-height`.

## Проверки правдоподобия

| Проверка | Порог | Что значит отказ |
|---|---|---|
| протяжённость контура / 1.9 | меньше 0.5 | контур схлопнулся |
| | больше 1.5 | контур мог выйти за комнату, нужен просмотр |
| площадь пола | 1–200 м² | масштаб или контур неверны |
| наибольший размер комнаты | 0.8–30 м | то же |

`freeze` исключает комнаты, не прошедшие проверки; `export` по умолчанию на них
останавливается.

Отчёт по комнатам — `state/metric_scale.json`. В `state/ground_truth.json` поле
`metric_scale_certified` равно `true`, только если масштаб всех комнат взят из таблицы.
