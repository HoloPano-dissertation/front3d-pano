# Источники данных и условия использования

Генератор не содержит и не распространяет данные 3D-FRONT. Пользователь скачивает
их сам и сам принимает условия правообладателей.

## Что нужно скачать

| Что | Откуда | Объём | Зачем |
|---|---|---|---|
| Комнаты GLB `3D-FRONT-SCENE` | [huanngzh/3D-Front](https://huggingface.co/datasets/huanngzh/3D-Front), 13 частей `3D-FRONT-SCENE.part*` | 484 ГиБ | мебель и конструкции каждой комнаты отдельными файлами; вход рендерера |
| Список комнат `valid_room_ids.json` | там же | мегабайты | комнаты, которые переработка считает пригодными |
| Описания сцен `3D-FRONT.zip` | исходный релиз 3D-FRONT | 2.1 ГБ | точные масштабы, классы предметов, архитектура комнат |
| Текстуры `3D-FRONT-texture.zip` | исходный релиз 3D-FRONT | 1.8 ГБ | материалы стен, полов и потолков |

Отрисованные виды (`3D-FRONT-RENDER`) и облака точек (`3D-FRONT-SURFACE`, около двух
третей всего архива) переработки MIDI-3D не нужны. Панорам среди готовых видов MIDI-3D
нет: это перспективные кадры мебели с орбиты снаружи комнаты. Модели 3D-FUTURE (четыре
архива по 7.5 ГБ) тоже не нужны: классы предметов записаны в описаниях сцен.

Распаковка комнат:

```bash
cat 3D-FRONT-SCENE.part* > 3D-FRONT-SCENE.tar.gz
tar -xzf 3D-FRONT-SCENE.tar.gz
```

Исходный релиз выдаётся на платформе Alibaba Tianchi после принятия лицензионного
соглашения. Если страница платформы недоступна, `3D-FRONT.zip` и `3D-FRONT-texture.zip`
можно взять из зеркала [JIAQI-CHEN/3D-Front](https://huggingface.co/datasets/JIAQI-CHEN/3D-Front).
Зеркало неофициальное, лицензия на нём не указана: условия исходного соглашения действуют
и для скачанных оттуда архивов.

## Почему нужны оба источника

Переработка MIDI-3D удобна: каждая комната — отдельная папка, каждый предмет — отдельный
GLB. Но у неё три особенности, из-за которых одной её мало:

1. **Каждая комната нормирована своим множителем.** Метры восстанавливаются по настоящим
   размерам мебели из `3D-FRONT.zip`, см. [metric_scale.md](metric_scale.md).
2. **Нет архитектуры комнат.** Примерно у трети комнат нет стен, а оставшиеся поверхности
   окрашены одним цветом без материала. Стены, полы, потолки, плинтусы, откосы и
   встроенные шкафы собираются заново из исходного релиза командой `architecture`.
3. **Грубые метки классов.** Точные классы берутся из описаний сцен исходного релиза.

## Условия использования

**Исходный 3D-FRONT** распространяется по лицензионному соглашению Alibaba
(«3D-FUTURE / 3D-FRONT Data Sets Use License Agreement»). Главное из него:

- данные используются **только в научных целях**, коммерческое использование запрещено;
- исходные данные нельзя передавать третьим лицам;
- производные работы (к ним относятся отрисованные панорамы и разметка) распространять
  можно, но тоже только для научных целей, с указанием источника данных и при условии,
  что получатели соблюдают то же соглашение;
- источник нужно указывать при публикации результатов и при передаче производных данных.

**Переработка MIDI-3D** ([huanngzh/3D-Front](https://huggingface.co/datasets/huanngzh/3D-Front))
распространяется по лицензии [CC BY-NC 4.0](https://creativecommons.org/licenses/by-nc/4.0/):
некоммерческое использование с указанием авторства. Указываются работа MIDI-3D
([arXiv:2412.03558](https://arxiv.org/abs/2412.03558)) и исходный 3D-FRONT.

**Код генератора** распространяется по лицензии MIT и данных не содержит. В репозитории
есть только идентификаторы комнат (`<дом>/<комната>`) в списках разбиения и причины
исключения комнат.

Поэтому панорамы и разметку, полученные генератором, можно передавать коллегам для
научной работы, указав оба источника (3D-FRONT и MIDI-3D) и предупредив получателей,
что на данные действуют те же условия.

Изложение выше — краткий пересказ, а не юридическая консультация. Действуют полные тексты
соглашения 3D-FRONT и лицензии CC BY-NC 4.0.
