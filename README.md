# front3d-pano

*[English version — README.en.md](README.en.md).*

Генератор панорам 360° с метрической трехмерной разметкой из комнат набора
**3D-FRONT**. По каждой комнате он ставит камеры, отрисовывает четыре
эквиректангулярные панорамы и выгружает разметку: трехмерные рамки предметов в метрах,
контур комнаты, отношения между предметами, сетки предметов, двумерные рамки и маски.

Генератор не зависит от конкретных методов. Он выдает разметку «как есть» и, кроме нее,
только общепринятый формат COCO. Форматы конкретных методов получаются отдельными
**адаптерами** вне генератора: они читают эталонную разметку, и ядро для них не меняется.

## Что получается на выходе

| Слой | Что в нем | Зависит от методов |
|---|---|---|
| Рендер | на каждый вид: цвет, глубина, нормали, маски экземпляров (`{0..3}.hdf5`), камеры и параметры (`render.json`) | нет |
| Эталонная разметка | трехмерные рамки предметов в метрах, контур комнаты, отношения, классы, сетки предметов, разбиение по домам | нет |
| COCO | двумерные рамки и маски предметов | нет |

Формат каждого файла описан в [docs/output_format.md](docs/output_format.md).

## Как устроен конвейер

```
комнаты GLB (переработка MIDI-3D)  +  исходный 3D-FRONT (масштабы, классы, архитектура)
        │
        ▼  metadata → freeze → init → architecture
состав набора: разбиение по домам и исключенные комнаты с причинами
        │
        ▼  render (Blender через BlenderProc) → reject
панорамы: outputs/<часть>/<дом>/<комната>/{0..3}.hdf5 + render.json
        │
        ▼  export → validate
эталонная разметка и COCO
        │
        ▼  images → publish
набор в том виде, в каком им делятся
```

Подробно по шагам — [docs/pipeline.md](docs/pipeline.md).

## Установка

Нужен Python 3.9 или новее. Разметка и проверки работают на процессоре:

```bash
git clone https://github.com/HoloPano-dissertation/front3d-pano.git
cd front3d-pano
python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
front3d-pano --help
```

Для рендера дополнительно нужен BlenderProc. Он сам скачивает Blender при первом
запуске. Проверено с BlenderProc 2.8.0 и Blender 4.2.1 на Linux:

```bash
pip install -e ".[render]"
blenderproc pip install "shapely>=2,<3"
```

## Одна комната

```bash
front3d-pano render-room /data/3D-FRONT-SCENE/<дом>/<комната> /data/rendered-room \
  --views 4 --samples 96 --min-clearance 0.1 --ambient 4.0 --light-temperature 2700-5000
```

В папке появятся `{0..3}.hdf5` и `render.json`, как читать HDF5 — в
[docs/output_format.md](docs/output_format.md). Стены и пол из исходного 3D-FRONT подключаются ключом
`--architecture` (см. [docs/pipeline.md](docs/pipeline.md), шаг 4).

## Команды

Все шаги вызываются одной командой `front3d-pano <команда>`, ключи каждой команды
выводит `front3d-pano <команда> --help`.

| Команда | Что делает |
|---|---|
| `metadata` | точные покомнатные масштабы и классы предметов из исходного 3D-FRONT |
| `freeze` | разбиение по домам и список исключенных комнат с причинами |
| `init` | новый эксперимент по зафиксированному разбиению |
| `architecture` | стены, полы, потолки и их материалы из исходного 3D-FRONT |
| `render` | план камер и рендер панорам для многих комнат, с шардами и возобновлением |
| `render-room` | рендер одной комнаты |
| `reject` | перевод в исключения комнат, которые не смог снять рендерер |
| `export` | вся разметка: цвет, эталон в метрах, отношения, сетки, COCO |
| `validate` | сверка выгрузок между собой |
| `images` | цвет всего набора в PNG |
| `publish` | набор в том виде, в каком им делятся: панорамы, COCO и README |

## Данные и условия использования

Данные в репозиторий не входят, их нужно скачать отдельно. Используются комнаты GLB из
переработки MIDI-3D ([huanngzh/3D-Front](https://huggingface.co/datasets/huanngzh/3D-Front),
лицензия CC BY-NC 4.0) и два архива исходного 3D-FRONT: описания сцен и текстуры.
Исходный 3D-FRONT распространяется по лицензионному соглашению Alibaba только для
научных целей. Что скачивать и какие условия принимает пользователь, описано
в [docs/data_sources.md](docs/data_sources.md).
